02 —Stack & pipeline

Stack

PythonPandasSQLClickHouseAirflow Docker ComposePower BIDBeaverExcel Hermes AgentOpenCode9RouterOrca IDECamofoxGit

Principles

Every .md is generated by a script (stdlib). Draft → final promoted byte-identical (cp + cmp). No hand-written numbers. Every FACT cites a record ID.

Pipeline — briefs → deliver

briefs/ — research questions & intake
data/sources/ — Camofox, immutable evidence
data/raw → processed/ — OpenCode extract + normalize
analysis/ — numbered scripts 01..11_*.py
reports/drafts → final/ — Hermes verify, byte-identical promote
reports/presentations/ — executive .pptx decks

Also running in prod — data platform

CDC: Postgres wal_level=logical → Debezium → Redpanda
Serve: ClickHouse analytics · Airflow orchestration · Metabase BI
